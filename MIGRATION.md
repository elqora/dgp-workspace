# Workspace migration evidence

DGP Workspace preserves the complete framework-neutral editorial system proven by the legacy engine. The historical `src/react/canvas` location contains no React components and is binding Workspace evidence. React bindings and rendered presentation move to Studio; Editor, `CanvasAPI`, Selection, Comments, and all underlying state and commands remain here. The current implementation is a backend/session slice, not a complete Workspace migration.
